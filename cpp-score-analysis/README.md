# C++ Score Analysis Program

This project demonstrates the use of arrays, pointers, and functions in C++ to analyze numerical data.

## Concepts Demonstrated
- Arrays
- Pointer parameters
- Functions
- Looping and conditionals
- Basic statistical calculations

## Overview
The program processes a set of test scores and calculates the highest score, lowest score, and average score.

## Tools Used
- C++
- g++
- Ubuntu Linux
