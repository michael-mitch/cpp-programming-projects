# C++ OOP Health Metrics Program

This project demonstrates object-oriented programming concepts in C++ using inheritance, constructors, and method overriding.

## Concepts Demonstrated
- Classes and objects
- Inheritance
- Constructor overloading
- Virtual methods
- Method overriding
- Mathematical calculations

## Overview
The program models patient health data and calculates metrics including BMI and Body Surface Area (BSA). A derived cardiac patient class extends the base patient class with heart rate tracking.

## Tools Used
- C++
- g++
- Ubuntu Linux
