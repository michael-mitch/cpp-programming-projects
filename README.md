# C++ Programming Projects

This repository contains hands-on C++ programming projects focused on object-oriented programming, data analysis, and core software development concepts.

## Skills Demonstrated
- Object-oriented programming (OOP)
- Inheritance and polymorphism
- Constructors and method overriding
- Arrays and pointers
- Functions and parameter passing
- Mathematical and statistical calculations
- Linux-based C++ development

## Tools Used
- C++
- g++
- Ubuntu Linux
- VMware Workstation

## Projects

### Health Metrics OOP Program
An object-oriented C++ application that models patient health information and calculates metrics such as BMI and Body Surface Area (BSA). Demonstrates inheritance, constructor overloading, and virtual method overriding.

### Score Analysis Program
A C++ program that analyzes an array of scores and calculates the highest score, lowest score, and average using functions and pointer parameters.

## Notes
These projects were developed as part of hands-on C++ programming practice using Linux and command-line compilation tools.
